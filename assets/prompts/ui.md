# Neon Breach UI Asset Prompts

## Global UI Direction

Style:
Dark sci-fi, neon cyberpunk, clean futuristic HUD, high contrast, sharp beveled edges, glowing cyan outlines, professional indie roguelike shooter quality.

Colors:
Dark navy and black base, cyan and electric blue highlights, small accents of red, green, purple, and gold.

Background:
Transparent PNG unless noted otherwise.

Avoid:
Cartoon style, mobile ad style, low-detail clipart, text embedded in images, white backgrounds, watermarks.

Naming convention:
`ui_{asset_name}_{variant}.png`

## Required Asset Sizes

Use these dimensions unless a later prompt says otherwise.

Full-screen UI backgrounds:
16:9, 3840x2160 master, export down to 1920x1080 if needed.

Wide HUD panels:
2:1, 1024x512.

Long HUD strips:
4:1, 2048x512.

Upgrade cards:
3:4 portrait, 768x1024.

Square icons:
1:1, 512x512.

Large boss or character portraits:
1:1, 1024x1024.

Radar and minimap panels:
4:3, 1024x768.

Button and ability controls:
1:1, 512x512.

Thin bars:
8:1, 2048x256.

All final game assets should be PNG with transparent background unless the asset is explicitly a full-screen background.
